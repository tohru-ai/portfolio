整骨院の事務作業はAIでどこまで減らせるか

ホーム ／ AI活用コラム ／ 導入事例

  2. 予約の二重入力が毎日の負担になる
  3. AIは調べものと下書き止まりだった
  4. 予約の自動化を設計した実演

施術が終わってから、予約の整理とLINEの返信。気づけば毎晩、受付の机に向かっている。

おひとりで整骨院・接骨院を回していると、こうした夜は珍しくないのではないでしょうか。

この記事では、私が実際に支援した接骨院の例をもとに、AIでどこまで事務作業を減らせるのかを整理します。

ひとりで回す院の事務作業は意外と多い

院長がひとりで運営する院では、施術以外の作業もすべて院長の仕事になります。まず、どこに時間がかかっているかを見ていきます。

予約の二重入力が毎日の負担になる

支援した接骨院は、院長おひとりで運営し、来院は1日約10件でした。予約はLINE・電話・店頭の3つから入ります。

予約が入るたびに、紙の台帳で空きを確かめて書き込み、さらに Googleカレンダーにも入力していました。1件あたり約1分、1日10件で10〜20分です。

1日10〜20分でも、1か月にすると数時間になります。

AIは調べものと下書き止まりだった

この院長は、ChatGPT と Claude を使ったことがありました。ただ、使い道は記事の骨組みづくりや、迷ったときの相談まで。AIは「調べものと下書きの道具」という見え方でした。

予約の自動化を設計した実演

60分のオンライン相談で、予約の仕事を題材に、AIに作業を任せる流れを実演しました。

LINE予約からカレンダー登録まで

Claude Code（指示すると自分でプログラムを書いて動かすAI）を使い、次の流れを設計しました。

  1. 公式LINEに「予約」と送ると、予約ページのURLが自動で返る
  2. 患者さんが空き枠のページを見て、タップで予約する
  3. 確定すると Googleカレンダーに自動で登録される
  4. 院長と患者さんの両方にLINEで通知し、前日18時に自動でお知らせする

予約の仕組みの骨子は、実演のなかで約20分で形になりました。

院長がいちばん驚いたこと

院長がいちばん反応したのは、AIが自分でファイルを作り、作業の許可を求めてくる様子でした。

ChatGPT などは考えを返してくれる存在です。それに対して、Claude Code のようなAIは実際に手を動かします。「考える」だけでなく「作業する」AIがあると分かったことで、見え方が大きく変わりました。

個人事業主と相性が良い理由

自動化には、LINEやGoogleなど外部サービスとの連携を許可する手続きが必要です。会社員は自社の仕組みの権限を持っていないことが多いのに対し、院長は自分で許可を出せます。ひとりで運営する院は、自動化を進めやすい環境です。

AIに任せる作業と人が残す作業

すべてをAIに任せる必要はありません。整骨院の事務作業を、任せやすいものと人が残すものに分けて考えます。

任せやすい作業

  • 予約の受付と、カレンダーへの登録
  • 予約の前日のお知らせ
  • よくある質問への返信の下書き
  • ブログやお知らせの文章の下書き

人が残す作業

  • 施術の内容や体の状態に関わる判断
  • 患者さんの個人情報の管理
  • 返信の最終確認

患者さんの健康に関わる情報は、AIに入れる前に扱いを決めておきます。予約のように、名前と日時だけで済む作業から始めると安心です。

最初の1つを選ぶチェック

  • 毎日くり返している作業か
  • 入力や転記など、手順が決まっているか
  • 間違えても人が見直せば取り返せるか

まとめ

おひとりで回す整骨院・接骨院でも、AIで減らせる事務作業はあります。

  • 予約の二重入力は、受付からカレンダー登録まで自動化する流れを設計できる
  • AIには「考える」ものと「作業する」ものがある
  • 健康に関わる判断と個人情報は人が持つ

まずは予約のように、毎日くり返す作業1つから始めるのがおすすめです。

よくある質問

パソコンが得意でなくても導入できますか？

何を自動化するかの整理から、仕組みづくり、使い方の説明まで一緒に進めます。操作に不安がある方も、まずは無料相談でお聞かせください。

患者さんの情報をAIに入れても大丈夫ですか？

入れてよい情報と入れない情報を、最初に一緒に決めます。予約のように名前と日時だけで済む作業から始めると安心です。
